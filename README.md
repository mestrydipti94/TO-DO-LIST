# Todo List App

A simple Todo List practice project built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Delete tasks
- Prevent empty task submission
- Save tasks using Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Practiced
- DOM Manipulation
- Event Listeners
- Functions
- Local Storage
- JSON (parse and stringify)

## Purpose
Created as a practice project to improve my JavaScript fundamentals and DOM manipulation skills.
